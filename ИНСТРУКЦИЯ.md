# Инструкция по запуску проекта "LUNG CANCER AI"

Этот проект представляет собой веб-интерфейс для прогнозирования риска рака легких на основе обученной модели машинного обучения (CatBoostClassifier).

---

## 📦 Как подготовить проект к отправке (Создание ZIP)

Чтобы архив был компактным и корректно открылся у руководителя, следуйте этим шагам:

1.  **Удалите лишнее**: НЕ включайте папку `venv` и `__pycache__` в архив. Они весят много и создаются заново на компьютере получателя.
2.  **Обязательные файлы**: Выделите следующие файлы и папки:
    *   `app.py` — основной файл сервера.
    *   `static/` — папка со стилями и скриптами интерфейса.
    *   `templates/` — папка с HTML-шаблоном.
    *   `requirements.txt` — список необходимых библиотек.
    *   `dataset_final.csv` — база данных.
    *   `best_model.pkl` (и другие `.pkl`) — обученные модели.
3.  **Создайте архив**: Нажмите правой кнопкой на выделенные файлы -> *Отправить* -> *Сжатая ZIP-папка*. Назовите её, например, `Lung_Cancer_AI_Project.zip`.

## 🚀 Инструкция по запуску (для руководителя)

Для запуска проекта на компьютере должен быть установлен **Python 3.10+**.

### Шаг 1: Распаковка
Распакуйте содержимое архива в любую удобную папку.

### Шаг 2: Создание окружения и установка библиотек
Откройте терминал (PowerShell или CMD) в папке проекта и выполните команды:

```bash
# 1. Создание виртуального окружения
py -m venv venv

# 2. Активация окружения
# Для Windows:
.\venv\Scripts\activate
# Для Mac/Linux:
source venv/bin/activate

# 3. Установка необходимых зависимостей
pip install -r requirements.txt
```

### Шаг 3: Запуск приложения
После установки всех библиотек запустите сервер:

```bash
py app.py
```

### Шаг 4: Просмотр результата
После появления в терминале надписи `Running on http://127.0.0.1:5000`, откройте любой браузер и перейдите по адресу:

👉 **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

## 🛠 Технические особенности системы
*   **Интерфейс**: Современный "стеклянный" дизайн (Glassmorphism) с адаптацией под мобильные устройства.
*   **Аналитика**: Система не просто выдает "да/нет", а анализирует **индекс курильщика (Pack-Years)** и симптоматический кластер, предоставляя детальный отчет.
*   **Безопасность**: Все расчеты производятся локально на сервере Flask.
